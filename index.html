Ejercicios de CSS y Responsive Design

Flexbox, media queries y box model aplicados a un set de tarjetas

Diseño Flexible

Esta tarjeta forma parte de un contenedor Flexbox que organiza las tres tarjetas en una sola fila, distribuyendo el espacio entre ellas.

Responsive Design

Al reducir el ancho de la pantalla por debajo de 768px, las tarjetas dejan de estar en fila y se apilan una debajo de otra.

Box Model

Cada tarjeta tiene padding interno, margen externo, un borde sutil y una sombra que le da profundidad visual.
