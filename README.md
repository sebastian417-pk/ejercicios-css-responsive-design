# Ejercicios de CSS y Responsive Design

Proyecto práctico para afianzar conceptos de CSS y diseño responsive.

## Contenido

El archivo `index.html` incluye tres ejercicios (HTML y CSS en el mismo archivo):

1. **Flexbox**: 3 tarjetas en fila, cada una con título, descripción y color de fondo distinto.
2. **Media query**: en pantallas menores a 768px las tarjetas se apilan verticalmente y ocupan el 100% del ancho.
3. **Box model y sombras**: las tarjetas tienen padding, margin, border y box-shadow para dar profundidad.
